# SafePlace design exports

PNG exports of the SafePlace brand kit and web interface examples.

Source: [Figma design file](https://www.figma.com/design/9tatIII5caffv6gJmdlH3t/Logotipo). Exported on 2026-09-06.

## Contents

| Folder | PNG files | Content |
| --- | ---: | --- |
| [brand-kit](brand-kit/) | 6 | Brand strategy, logo guidelines, colors, typography, and applications |
| [brand-assets](brand-assets/) | 15 | Asset overview, logo and symbol variants, feedback badges, and color swatch |
| [web-ui](web-ui/) | 9 | Component reference boards and SafePlace interface examples |
| [components](components/) | 78 | Individual component states and icons |

The 108 PNGs use the native export size (1x), including visible strokes outside component bounds. Transparent assets retain their alpha channel. Inverse logos and symbols are white and should be viewed over a dark background.

The Figma file contains the editable components. These PNGs are static snapshots. Example names, dates, equipment records, and risk classifications are fictional.

[manifest.json](manifest.json) maps every PNG to its Figma node and records its dimensions, byte size, and SHA-256 checksum.
