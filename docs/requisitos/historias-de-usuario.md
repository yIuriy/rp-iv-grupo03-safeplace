# Histórias de Usuário do SafePlace

Este documento reúne somente as histórias de usuário do SafePlace. Cada história possui uma tabela própria com ator, objetivo, valor e frase completa.

O Colaborador é uma pessoa cadastrada, mas não possui conta, senha ou acesso ao sistema. O Supervisor realiza os registros relacionados aos Colaboradores.
